# 万象 ↔ 知枢 联调清单（阶段 5）

知枢 AI 与 `zhishu-core` **同进程**，库仅 `zhishu_integrable_framework`。监测 Tool 在万象 `wanxiang-mcp`。

详见万象仓 `docs/联调清单.md` 与 `docs/知枢拆分最终方案.md`。

## 本仓启动（同机默认）

```text
backend/zhishu-core  profile=dev  :8180
frontend            :3100
```

```powershell
# 知枢仓根目录
.\start-all.cmd
```

## 必须补丁（zhishu_integrable_framework）

- `backend/zhishu-core/src/main/resources/db/init_ai.sql`（全新库）
- `backend/zhishu-core/src/main/resources/db/patch_wanxiang_mcp_upstream.sql`
- `backend/zhishu-core/src/main/resources/db/patch_open_app_wanxiang.sql`
- `backend/zhishu-core/src/main/resources/db/patch_ai_menus.sql`
- `backend/zhishu-core/src/main/resources/db/patch_align_wanxiang_users.sql`
- `backend/zhishu-core/src/main/resources/db/patch_webhook_delivery.sql`

## 图谱（可选）

- 知枢 `application.yml`：`wanxiang.kg.enabled` 默认 `false`；配置 Neo4j 后设 `WANXIANG_KG_ENABLED=true`
- 万象 dev 可推送实体至知枢 `POST /open/v1/kg/upsert`

## SSO

- 万象私钥：`wanxiang-monitor-platform/docs/dev-keys/wanxiang-private.pem`（gitignore，本地生成）
- 知枢公钥：`backend/zhishu-core/src/main/resources/sso/wanxiang.pem`
- 万象 `wanxiang.sso.zhishu.zhishu-web-base` → `http://localhost:3100`

## 禁止

- 配置万象 `wanxiang_monitor` JDBC
- 再启动万象根目录已退役的 `ai-assistant :8180`
- 扫描 `t_terminal` / `sys_user_project` 等万象业务表
